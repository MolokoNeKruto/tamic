# Голос в кадре

Обычный портрет, в котором живёт ещё одно состояние человека. Прикосновение — и кадр обретает голос, переставая быть просто изображением. Это место, где фотография отвечает.

В каждом кадре спит голос, который ждёт своего часа. Прикосновение снимает с него тишину — и человек заговаривает. Так начинается серия: кадр за кадром, голос за голосом. Скоро среди них будет и твой человек.
