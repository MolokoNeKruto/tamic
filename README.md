# Тамик — звуковой режим

Нажми на фото: обычный Тамик переворачивается в музыкального и сразу говорит свою фразу.
Плеер рядом с карточкой управляет только звуком — сам Тамик он не переключает.

## Особенности

- Фраза в `assets/tamic-voice.mp3` обрезана до начала речи: тишины в начале больше нет.
- В плеере можно заменить звук своим аудиофайлом и вернуть оригинал.
- Визуализация строится по реальным частотам звука через Web Audio API.
- Всё работает и на компьютере, и на телефоне.

## Файлы

- `index.html` — разметка
- `styles.css` — дизайн и анимации
- `app.js` — звук, плеер, наклон карточки и визуализация
- `assets/` — изображения и MP3
