# Тамик — звуковой режим

Обычный Тамик превращается в музыкального по нажатию: 3D-переворот карточки,
звук из MP3 и живая визуализация.

Откройте `index.html` напрямую или включите GitHub Pages в этом репозитории.

## Файлы

- `index.html` — разметка
- `styles.css` — дизайн и анимации
- `app.js` — звук, плеер, 3D-наклон и визуализация
- `assets/` — два изображения и MP3
