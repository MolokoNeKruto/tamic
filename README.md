# Тамик — звуковой режим

Один экран без скролла. Нажми на Тамика — он переключится в музыкальный режим
и сразу произнесёт фразу. Кнопка «Плеер» раскрывает панель с визуализацией.

## Особенности

- Переход Тамика — заранее закодированное видео (`tamic-on.mp4` / `tamic-off.mp4`),
  а не тяжёлая CSS-3D-анимация. Видео декодируется железом телефона.
- Панель плеера «вытекает» из кнопки, меню настроек — из шестерёнки.
- Визуализация строится по реальным частотам звука через Web Audio API.
- Звук можно заменить своим файлом и вернуть оригинал.
- Прогресс-бар движется плавно.

## Файлы

- `index.html`, `styles.css`, `app.js`
- `assets/` — изображения, обрезанная фраза и видео-переходы
